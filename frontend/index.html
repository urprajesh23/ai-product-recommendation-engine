🚀 3-Step Integration

Copy-paste these snippets into your existing storefront to go live instantly.

Step 1

Fetch Personalized Recommendations

Call the /recommend endpoint with the currently logged-in user's ID. The engine will automatically A/B test between models.

// Add this to your product listing page
async function loadNexusRecommendations(userId) {
  const response = await fetch('http://your-nexus-api.com/recommend', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      user_id: userId,          // The logged-in customer's ID
      n_recommendations: 8,   // Number of products to show
      filter_purchased: true  // Don't re-recommend bought items
    })
  });
  const data = await response.json();
  renderProductCards(data.recommendations); // Your own render function
}
Step 2

Track Customer Clicks (A/B Signal)

When a customer clicks a recommended product, fire this event. This feeds the live A/B testing engine so it can determine the winning model.

// Attach to your product card "View" or "Add to Cart" button
function onProductClick(userId, itemId, variant) {
  fetch('http://your-nexus-api.com/ab-test/click', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      user_id: userId,  // Who clicked
      item_id: itemId,  // What they clicked
      variant: variant  // 'v1' or 'v2' from /recommend response
    })
  });
}
Step 3

Monitor Your Live A/B Dashboard

Poll the stats endpoint to track which AI model is winning for your customers. Use this to make data-driven deployment decisions.

// Call this to get live performance metrics for your dashboard
async function getABStats() {
  const response = await fetch('http://your-nexus-api.com/ab-test/stats');
  const stats = await response.json();
  
  console.log(`Model V1 CTR: ${(stats.v1_ctr * 100).toFixed(2)}%`);
  console.log(`Model V2 CTR: ${(stats.v2_ctr * 100).toFixed(2)}%`);
  console.log(`Winner: ${stats.winner || 'Need more data'}`);
  
  // Automatically promote the winner when you have enough data
  if (stats.winner === 'v2 (Hybrid)') deployHybridModel();
}
