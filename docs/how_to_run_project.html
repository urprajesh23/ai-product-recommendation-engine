💻 The Only Times You Need a PowerShell Command

Situation Command to Run Where
🔄 Starting the project after a PC restart docker compose up -d PowerShell in project folder
🔨 Rebuilding after you changed code docker compose up -d --build PowerShell in project folder
⛔ Stopping the project to free memory docker compose down PowerShell in project folder
🔍 Checking which containers are running docker ps Any PowerShell window
📋 Reading live server logs docker logs recommender-api Any PowerShell window
